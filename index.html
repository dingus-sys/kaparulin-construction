How a project runs

From walkthrough to final walk

  1. Walkthrough

    We come out, measure, and talk through what you have in mind. If it's easier, text us photos of the space first.

  2. Materials

    We hold a Washington reseller permit, so we can source tile and stone for you. We're just as happy to install what you've already picked.

  3. Prep

    Demo, leveling, slope, backer board, and waterproofing. You won't see this part when we're done, and it decides how long everything lasts.

  4. Install

    We set, grout, and seal, then clean up and walk the finished space with you.
